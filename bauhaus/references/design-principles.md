# Graphic Design Principles for Bauhaus

## 1. Visual Hierarchy
- **Primary focal point**: Must be identifiable within 1 second (usually the headline, hero visual, or key offer).
- **3-level typographic hierarchy**:
  1. Display / Headline (largest, highest weight or contrast)
  2. Subheadline / Key metadata (date, venue, value proposition)
  3. Body / Supporting details / CTA (clean, readable, restrained)
- Use scale contrast (at least 2:1 between display and body), weight contrast, spatial isolation, and colour accent—not all at once.

## 2. Typography & Pairing
- Limit to **2 typefaces** per design (max 3 if adding a technical monospace accent).
- **Proven pairings**:
  - Technical / Hackathon: `Space Grotesk` or `Syne` (display) + `Inter` (body) + `JetBrains Mono` (metadata/badges).
  - Editorial / Event: `Playfair Display` (display) + `DM Sans` (body).
  - Modern Promo: `Outfit` or `Plus Jakarta Sans` (display) + `Inter` (body).
  - Multilingual (Malayalam / Hindi): Pair `Noto Sans Malayalam` or `Noto Sans Devanagari` with `Inter` or `DM Sans` at matched optical x-height.
- **Line height**: `1.0–1.15` for large display headlines; `1.35–1.55` for body copy.
- **Tracking**: Tighten display headlines slightly (`-0.02em` to `-0.03em`); open uppercase labels/eyebrows (`+0.08em` to `+0.16em`).

## 3. Colour Theory & Contrast
- Follow the **60-30-10 rule**: 60% dominant ground, 30% secondary surface/structure, 10% high-energy accent.
- Maintain **WCAG AA** contrast (`>= 4.5:1` for body text, `>= 3:1` for large display text).
- Avoid pure `#000000` on `#FFFFFF` when a softer editorial contrast (`#111318` on `#F7F5F0`) feels more refined; reserve high-saturation neon accents for dark-mode technical posters.

## 4. Layout, Grids & Negative Space
- Establish consistent outer margins (`5%–8%` of canvas width) and align related elements to shared grid columns.
- Leave **25%–40% negative space** so focal elements breathe.
- Never place text right up against container edges; give cards generous internal padding.
- Context awareness: a cybersecurity hackathon poster, a promotional social graphic, and a college cultural flyer must have distinct visual languages, not recycled templates.
